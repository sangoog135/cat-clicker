# КЛИКЕР «КОТ»

Игра-кликер про жёлтого кота. Платформа: веб + Android APK.

## Играть

- **В браузере:** открыть `index.html`
- **На телефоне:** `Кот-кликер-debug.apk`

## Как играть

Кликаешь **в любом месте экрана** — кот садится и радуется, начисляются мурлыки.
Всё. Больше ничего нет — это самый простой кликер в мире.

### Прокачка — по чуть-чуть

| Механика | Как работает |
|---|---|
| **Уровень** | Каждые 100 мурлыков — новый уровень |
| **ЗА КЛИК** | Сила клика = уровень. На 1 уровне клик даёт 1, на 10 — 10, на 100 — 100 |
| **Рост кота** | С каждым уровнем кот растёт на 7% (максимум ×2.4) |
| **Ходьба по холму** | Кот идёт точно по линии травы, а не по воздуху |
| **Разворот** | Дошёл до края — остановился, развернулся, пошёл назад |
| **Поймать кота** | Кликни по коту, пока он гуляет |

## Настройки

Кнопка **⚙ НАСТРОЙКИ** внизу:

- **Имя игрока** — вписывается в первую реплику кота («ПРИВЕТ, САША!»)
- **Язык** — РУС / ENG, переводится весь интерфейс и диалоги
- **Звук** — ВКЛ / ВЫКЛ
- **ОСЕННИЙ ЭВЕНТ** — золотая кнопка, открывает раздевалку
- **Сброс** — обнулить счётчик (купленная одежда остаётся)

Настройки сохраняются вместе с прогрессом.

## Раздевалка (осенний эвент)

В настройках → **ОСЕННИЙ ЭВЕНТ**: два предмета из рисунков Саши
(`осенний эвент.pxo` — плащ, `осенний эвент 2.pxo` — сапоги).

- Каждый стоит **10 000 000 мурлыков** (`WARDROBE.cost` в `js/data.js`)
- Купил — сразу надел; кнопка переключает **ОДЕТЬ / СНЯТЬ**
- Предметы лежат слоями поверх спрайта кота (`#catCos-coat`, `#catCos-boots`),
  тем же канвасом 64×64 — надеваются на все позы разом
- Купленное хранится в сейве (`state.cos.owned / worn`) и переживает сброс

## Сцена знакомства

Перед первой игрой: кот выходит из-за правого края → идёт к середине → стоит → садится →
и говорит с игроком.

- **Тап по экрану** — следующая реплика
- Когда кот говорит — он радуется, когда слушает — сидит
- В конце — кнопка **ИГРАТЬ**
- Кнопка **ЗНАКОМСТВО** внизу — пересмотреть

### Диалоги

`js/data.js` → `INTRO.dialog.ru` и `INTRO.dialog.en`.
`{name}` в тексте заменяется на имя игрока.

## Поддержка разработчика

Кнопка **ЗАДОНАТИТЬ** → окно с кнопкой **ПОДДЕРЖАТЬ**.
Ссылка задаётся в `js/data.js`:

```js
const DONATE = {
  url: '',      // ← сюда ссылка: Boosty, Telegram, Donationalerts...
  dev: 'SASHA'
};
```

Если `url` пустой — показывается только текст без кнопки.

```bash
cd android && ./gradlew assembleDebug
```

## Грабли (не ломать)

- **`inset: 0` не работает в WebView на Android** — элементы схлопываются в 0×0.
  Пишем `top: 0; right: 0; bottom: 0; left: 0`
- **`display: flex` перебивает атрибут `hidden`** — для `.game` нужно явное
  `.game[hidden] { display: none; }`
- **Два скрипта не могут объявлять `const $`** — `intro.js` и `i18n.js` обёрнуты в IIFE
- **Все игровые таймеры — только `performance.now()`**. Смешивать с `Date.now()` нельзя:
  `Date.now()` это epoch (~1.7e12), а `performance.now()` — от старта страницы (~5000),
  из-за чего условия вида `now < happyUntil` вечно истинны (кот «залипал» в радости)
- **CSS-версия для кэша**: правишь `style.css` / спрайты — поднимай `?v=N` в
  `index.html` (`css/style.css?v=14`), иначе браузер покажет старое
- **Одежда кота**: у `.cat img` в CSS стоит `opacity: 0` (мигание поз), а слои
  `#catCos-*` перекрываются правилом `#catCos-coat, #catCos-boots { opacity: 1 }`,
  а скрытие — только через `[hidden]` (`.cat img { display: block }` глушит
  атрибут `hidden`, нужно `.cat img[hidden] { display: none }`)
- **Предметы рисуются на полном канвасе 64×64**, а спрайты кота прижаты к низу
  (содержимое stand y36..63) — новые предметы из .pxo надо сдвигать вниз
  (плащ +24, сапоги +16), иначе «плащ надет на голову»
- `gap` в flexbox не работает в старых WebView Android → используем `margin`
- `transform` в keyframes ломает вёрстку в WebView → только `opacity`
- Копировать в `www/` надо **всё**: `index.html css js assets sprites` — иначе в APK
  попадут старые спрайты
- `INTRO.dialog` — объект `{ru, en}`, длину считать через `dialogList().length`
- **Спрайты переименованы:** `walk1/walk2` → `walkL1/walkL2` (ходьба влево),
  `walk3/walk4` → `walkR1/walkR2` (вправо). Старые пути в `intro.js` давали
  «текстуру без кота» — битые картинки. После переименования спрайтов проверяй пути:
  ```bash
  python3 - <<'EOF'
  import re, os
  for f in ['js/game.js','js/intro.js','js/i18n.js','js/data.js','index.html']:
      for m in re.findall(r"(?:sprites|assets)/[A-Za-z0-9_.-]+\.(?:png|ttf)", open(f).read()):
          if not os.path.exists(m): print('НЕТ:', f, '->', m)
  EOF
  ```
- **Звуки** — `assets/sounds/*.wav` (сгенерированы синтезом, ~70 КБ):
  `purr` — мурчание на клик, `meow` — «Поймал!», `levelup` — новый уровень,
  `blip` — переход реплик. Включаются через `js/sound.js` (`playSound(name, vol)`),
  выключатель «ЗВУК» — в настройках (настройка `sound` в `DEFAULT_SETTINGS`).
  Файлы wav можно заменить на свои (тот же путь/имя) — перекодировать в mp3 не нужно.
- **Донат** — `DONATE.url` в `js/data.js` (Donatty). Кнопка «ПОДДЕРЖАТЬ»
  открывает ссылку через `window.open('_blank')` — в Capacitor WebView это
  пробрасывается в системный браузер, проверено на эмуляторе.
- **Движение в сцене знакомства — вручную через `requestAnimationFrame`.**
  Ни CSS-`transition`, ни `element.animate()` в WebView на Android не срабатывали
  надёжно: кот оставался за правым краем экрана и не появлялся
- **`.cat-wrap` центрируется через `left:50%` + `margin-left:-95px`.** Если в CSS
  добавить `transform: translateX(-50%)`, а в JS ещё и `translateX(-50%)` — кот уедет
  на пол-экрана влево и будет не виден (был такой баг). Масштаб уровня вешаем
  как `scale()` без translateX, с `transform-origin: bottom center`
